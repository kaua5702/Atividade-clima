# Projeto Informações Climáticas ☁️🌡️

Este projeto foi **copiado e adaptado** com o objetivo de treinar a escrita de código e a adaptação a diferentes linguagens de programação.  
Ele exibe uma **tela com informações climáticas** de um determinado local, que pode ser facilmente alterado para qualquer outro.

## Objetivo
- Praticar a escrita de código em diferentes linguagens.
- Exercitar a adaptação de projetos existentes.
- Aprender conceitos relacionados a APIs e manipulação de dados climáticos.

# Exemplo de uso

Ao executar o programa, será exibida uma tela com informações como:

- Temperatura atual
- Condições climáticas (ex: ensolarado, chuvoso)
- Local consultado

Você pode alterar o local configurado para visualizar o clima de qualquer cidade.

# Tecnologias usadas
- HTML → estrutura da página
- CSS → estilização e layout
- JavaScript → lógica e integração com dados climáticos
